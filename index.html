Demo & scoring

Transparent local heuristics help explain this simulated triage.

  • +25 Known shortened URL pattern
  • +20 Brand absent from the domain, profile handle, or app listing ID
  • +20 Scam, phishing, urgency, prize, credential, or payment wording
  • +20 / +25 Impersonation cues in profile / app notes
  • +10 Indicator explicitly shared with another case
  • +10 Unencrypted HTTP URL

Scores are capped at 100; 0–39 low, 40–69 medium, 70–100 high. This is deterministic rule scoring, not a trained AI model or proof of fraud. Optional Google Safe Browsing URL lookups are manual and do not change the score.
